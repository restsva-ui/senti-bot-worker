# RemindIt Privacy Policy (draft)

_Last updated: 7 September 2026_

RemindIt is designed as a local-first reminder application.

## Data processed by the app

RemindIt can process reminder text, links, screenshots and photos that the user explicitly shares with or creates inside the app. It can also store reminder time, category, completion status and locally generated reminder meaning.

## Where data is stored

Reminder data and saved image originals are stored in RemindIt's private application storage on the user's Android device. RemindIt does not operate a user account system and does not upload reminder content to a RemindIt server.

Ukrainian OCR and English OCR run on the device. The Ukrainian OCR language model is bundled with the application build, so OCR does not require uploading images to a remote service.

## Internet access

The RemindIt 0.7 application does not request the Android INTERNET permission. When a user chooses to open a saved web link, Android hands that link to the user's browser or another compatible application.

## Notifications

RemindIt uses Android notifications and exact alarms to deliver reminders at the selected time. Notification visibility and lock-screen presentation are controlled by Android and the user's device settings.

## Saved originals

When a screenshot or photo is shared with RemindIt, the app may create a private local copy so the user can return to the original from the reminder. Deleting that reminder also deletes the associated local image copy when one exists.

For links, RemindIt stores the URL with the reminder so the user can open the original page later.

## Device backups

Android may include application data in device backup depending on the user's operating-system and backup settings. Such backup behavior is controlled by Android/device settings, not by a RemindIt server.

## Analytics and advertising

The current RemindIt beta does not include advertising SDKs, analytics SDKs or third-party tracking SDKs.

## Permissions

RemindIt may request permissions necessary for reminders, including notification permission and exact-alarm capability. These permissions can be changed by the user in Android Settings.

## Data deletion

Users can delete individual reminders inside RemindIt. Removing the app from the device removes its private application data according to Android's standard app-uninstall behavior, subject to any device backup settings controlled by Android.

## Changes

This policy may be updated as RemindIt gains new features such as optional cloud backup, synchronization, analytics or monetization. Any such feature should be reflected in this policy and in the Google Play Data safety declaration before release.

## Contact

A production support/contact address will be added before public Google Play release.
