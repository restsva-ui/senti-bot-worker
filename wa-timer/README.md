# WA Timer 1.0 MVP

Міні-додаток Android для локального планування повідомлень у групи WhatsApp через Accessibility UI automation.

## Що вміє
- група/підгрупа задається точною назвою, наприклад `кухарі`;
- довільний текст повідомлення;
- дата + час;
- одноразово, щодня або Пн–Пт;
- звичайний WhatsApp або WhatsApp Business;
- тестове надсилання одразу;
- журнал статусу;
- повторне планування після перезавантаження телефона.

## Важливі обмеження
1. Телефон не обходить PIN/пароль. Якщо він заблокований у момент таймера, завдання переходить у стан «Очікує розблокування».
2. Автоматизація залежить від UI WhatsApp. Якщо WhatsApp змінить назви/ID елементів інтерфейсу, селектори потрібно буде оновити.
3. Використовуйте для власних повідомлень, а не масового спаму.

## Перший запуск
1. Встановити APK.
2. На деяких Xiaomi/HyperOS для sideload APK: **Налаштування → Програми → WA Timer → ⋮ → Дозволити обмежені налаштування**.
3. У WA Timer натиснути **Увімкнути спецможливості** та активувати службу `WA Timer: надсилання в WhatsApp`.
4. Дозволити точні таймери.
5. Для Xiaomi/HyperOS бажано: Батарея → WA Timer → **Без обмежень**.
6. Ввести групу `кухарі`, текст і натиснути **ВІДПРАВИТИ ЗАРАЗ — ТЕСТ**.

## Збірка
Проєкт використовує AGP 8.7.3, Gradle 8.9, compileSdk 35, targetSdk 35, Java 17.

```bash
gradle assembleDebug
```

APK: `app/build/outputs/apk/debug/app-debug.apk`
